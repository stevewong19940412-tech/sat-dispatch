# 中国遥感卫星载荷成像参数规格（2026-11-09 检索）

## 1. 高分一号 GF-1（645km SSO 10:30）
- 相机类型：2×线阵推扫全色/多光谱（PMS）+ 4×宽幅WFV【真实值|CNSA/资源卫星中心】
- GSD/幅宽：全色2m、多光谱8m，60km（双相机拼）；WFV 16m/800km【真实值|gscloud.cn】
- TDI级数：未公开，用类别典型值（TDI CCD，32/64/96级按光照分档）
- 积分时间/像元：未公开【典型值|0.5m级像元10μm、积分时间~500-900μs】
- 量化位数：未公开【典型值|10bit】
- 侧摆：±25°，机动25°≤200s，应急±35°【真实值|o-map.cn GF-1手册】
- 成像模式：条带推扫、双机拼幅【真实值】

## 2. 高分二号 GF-2（631km SSO 10:30）
- 相机类型：2×线阵推扫PMS，全色/多光谱五谱合一TDI CCD，焦距7.8m F15【真实值|航天返回与遥感2015】
- GSD/幅宽：全色0.8m、多光谱3.2m，45km（双机拼，单机23km）【真实值|辐射质量评价论文】
- TDI级数：未公开（TDI CCD确认）【典型值|32/64/96级按太阳高度角】
- 积分时间/像元：未公开【典型值|~300-400μs，像元10μm】
- 量化位数：未公开【典型值|10bit】
- 侧摆：±35°，机动35°≤180s（≈0.2°/s）【真实值|星图云】
- 成像模式：条带推扫、双机拼幅【真实值】

## 3. 高分四号 GF-4（GEO 35786km，定点105.6°E附近）
- 相机类型：面阵凝视（VNIR 5谱段全局快门CMOS + MWIR HgCdTe面阵，滤光轮分光）【真实值|凝视相机技术特点论文】
- GSD/幅宽：VNIR 50m、MWIR 400m，幅宽>400km（单景>500km口径亦有）【真实值|CRESDA/中国气象局】
- TDI级数：不适用（面阵凝视，电子快门曝光）【真实值】
- 积分时间/像元：未公开（毫秒~秒级可调，凝视高频次连拍）【典型值|凝视曝光10ms~10s】
- 量化位数：未公开【典型值|10bit】
- 侧摆：指向控制实现中国及周边观测，具体角度未公开【典型值|±可覆盖全国】
- 成像模式：凝视、高频次连续拍摄（秒级间隔）【真实值】

## 4. 高分六号 GF-6（SSO）

- 成像模式：条带推扫、拼幅、动态像移匹配提升【真实值】

## 字段规格总表

| 字段 | 类型 | 单位 | 取值来源分类 |
|---|---|---|---|
| satName | string | - | 系统型号库 |
| cameraType | enum | linePushbroom/areaStaring/SAR | 真实值（官方发布） |
| gsdPan / gsdMs | float | m | 真实值；查不到用类别典型值 |
| swathKm | float | km | 真实值（幅宽=决定覆盖窗的核心字段） |
| tdiLevels | int[] | 级 | 真实值稀少，默认典型值[8,16,32,64,96]按太阳高度角分档 |
| tdiForSolarElev | map | 级↔° | 典型值：<15°→最高级，15-30°→中高档，>30°→低档（依据在轨自主调整方法论文二维查找表机制） |
| integrationTime | float | μs | 典型值：按像移速度匹配 t=GSD/v_ground 反算（0.3m→~100μs，0.5m→~180μs，2m→~700μs，16m→~5600μs） |
| pixelSize | float | μm | 典型值：高分5-10μm，商业敏捷5-8μm |
| quantBits | int | bit | 真实值（SV-1/Neo-1=11bit）；其余典型值10bit（高分系）/12bit（商业新） |
| rollMaxDeg | float | ±° | 真实值：GF-1±25(应急35)/GF-2±35/ZY-3±32/SV-1±45/Neo±45~50/视频星±45 |
| slewRate | float | °/s | 真实值换算：GF-1 25°/200s≈0.13、GF-2 35°/180s≈0.19；其余典型值0.5-1.5（敏捷星） |
| imagingModes | enum[] | - | 真实值：strip/multiStrip/stereo/multiTarget/areaStaring/inertial/sarStrip/sarSpot |
| sarBand / sarRes | string/float | -/m | 真实值：海丝C波段1m |
| videoStaring | object | - | 真实值：凝视类（GF-4 50m/400km；吉林视频0.92m/120s） |
