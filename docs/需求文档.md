# 卫星任务规划系统（底座迁移）需求文档

状态：已确认
一句话摘要：把「全球开源情报工作台」中卫星能力独立迁移，**收敛为遥感卫星任务规划底座**：只保留遥感卫星星座，补齐遥感卫星数量，面向遥感卫星做任务规划。

## 1. 目标与成功信号

- **目标**：原工作台体量大、模块耦合，无法直接作为卫星任务规划的工程起点。本项工作把卫星能力整体抽出，并按新定位收敛——**只保留遥感卫星**，补齐遥感卫星数量，形成一个数据真实、可独立运行的遥感卫星任务规划底座。
- **成功信号**：
  1. 新系统不依赖原项目即可启动运行，遥感态势、过境预报、任务管理全部可用；
  2. 遥感卫星星座完整：原库约 96 颗遥感相关卫星全部迁入，并补充高分、遥感、高景、吉林一号等主流遥感系列；
  3. 后续遥感任务规划功能（成像需求汇聚、任务编排、资源调度）可以直接在此底座上扩展。

## 2. 目标用户、最大价值与关键场景

- **目标用户**（已确认）：卫星任务规划业务人员 + 后续二次开发团队。
- **最大价值**（已确认）：数据真实、态势直观的**遥感卫星底座**——规划人员直接看遥感星座、预报过境、管成像任务；工程团队快速叠加规划算法。
- **关键场景**：
  1. 打开系统即在三维地球上看到遥感星座（光学成像/SAR/气象/成像侦察）实时位置与轨道；
  2. 按类别/搜索筛选遥感卫星，查看卫星档案（轨道参数、载荷类型、任务说明、运营方）；
  3. 指定地面观测点，预报未来 24 小时过境（升落时刻、最大仰角、方位角、持续时间）；
  4. 圈定关注区域（AOI），创建成像侦察任务并指派遥感卫星，跟踪任务状态。

## 3. 核心业务流程

```
打开系统 → 三维遥感星座态势（实时位置/轨道环/按遥感类别分组）
    → 筛选/搜索卫星 → 卫星档案（档案/覆盖/历史轨迹）
    → 过境预报（观测点 → 24h 过境窗口）
    → 圈定 AOI → 创建成像任务 → 指派遥感卫星 → 任务跟踪/执行/归档
```

### 明确不做（本版剥离，D-1 已拍板直接移除）

- 非遥感卫星类别：星链/OneWeb/铱星、北斗/GPS/GLONASS/伽利略、空间站、通信卫星（WGS/AEHF）、天文科学卫星（哈勃/XMM/SDO 等）——从库中剥离，不展示；
- 新闻/文章采集与情报核查、SIGINT 相机、全球设施库、情报流/监视子面板、AI 助手面板；
- 卫星档案中的「关联设施」「威胁评估」子面板（依赖情报库，随情报模块一并移除）。

### 遥感卫星范围界定（待确认 Q-1）

当前界定口径（草案）：
- **光学/雷达成像**：WorldView、Pleiades、Sentinel、TerraSAR、ALOS、GeoEye、ICEYE、高分、高景、吉林一号等；
- **成像侦察**：KH-11 系列、NROL 成像星、YAOGAN 遥感系列、COSMOS 成像侦察；
- **气象对地观测**：风云、NOAA、METOP、GOES、Himawari、METEOSAT 等（GEO 气象星成像固定区域，仍保留）；
- **对地观测科学星**：Terra/Aqua/Aura、Landsat、Sentinel-3、CRYOSAT、SDGSAT、SWARM、GCOM-W 等。

### 补充卫星获取方式（待确认 Q-2）

- 原库遥感底数约 96 颗，其中中国遥感卫星偏少（仅风云系列 + 遥感-12/31B + SDGSAT 等）；
- 拟补充：**高分系列（GF-1~GF-7、高分多模、高分SAR）、遥感(YAOGAN)系列、高景 SuperView-1、吉林一号、资源系列、天绘系列**及国际主流商业遥感星（Radarsat-2、Cartosat、Resurs-P、Capella 等），目标规模 150~200 颗；
- 获取方式：平台联网通道可访问境外数据源（原项目 TLE 即来自 CelesTrak 体系），抓取**真实 TLE + 轨道参数**入库；抓取失败的个别卫星如实标注。

## 6. 业务规则、异常与边界场景

- 过境预报最小仰角默认 5°、时限 24 小时、最多返回 10 次过境（沿用原系统参数）；
- TLE 星历有龄期，界面保留星历龄期提示（TleAgeBadge）；
- 补充卫星若个别抓取不到 TLE，不编造数据，在档案中标明「星历待补」；
- 卫星档案中依赖原情报库的数据一律移除，不显示空壳面板；
- 任务状态流转：规划中 → 进行中 → 暂停/已完成 → 已归档；
- 原库个别历史重复条目（ISS 双记录等）随剥离自然消失；保留条目若有重复，忠实迁移不清洗。

## 10. 风险、依赖、假设与待决定事项

- **风险-1**：Orbit.tsx 4391 行与情报模块代码级耦合，剥离需小步拆解保持可运行；
- **风险-2**：三维地球贴图来自外网 CDN，断网部署需本地化；
- **风险-3**：补充卫星 TLE 依赖平台联网通道抓取，个别卫星可能抓取失败——如实标注「星历待补」，不编造；
- **风险-4**：原库星历历元为 2026-08，随时间推移预报误差增大（保留龄期提示暴露）；
- **假设-1**：运行环境以当前沙盒为准，数据库用沙盒可用方案承载；
- **待决定**：Q-1 遥感范围界定口径；Q-2 补充卫星获取方式。
