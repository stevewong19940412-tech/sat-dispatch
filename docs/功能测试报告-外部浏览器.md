## 关键链路实测记录（T5→T6 全流程）

1. API 建测试任务（北京城区光学 2m，id=969）→ confirm 确认 → candidates 跑出 33 条候选；
2. 外部浏览器打开工作台 → 点详情 → 「派给公司」→ 三方式弹窗正确显示（候选 30 条截断提示）；
3. 点「向所有候选公司发起竞价」→ 顶部绿色提示"竞价已发起: 主单 PO-20261110-001，询价 2 家"；
4. 任务状态变「已派发」，关联订单区块出现 PO-20261110-001（长光卫星·询价）+ 公司接单按钮。
